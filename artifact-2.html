Case study 01 · Traditional ML

Email spam filtering

Examines conventional classifiers using manually selected or transformed text features, such as word counts and TF-IDF. For a modest labeled dataset and resource-conscious deployment, a traditional classifier is a practical starting point.

Case study 02 · Deep learning

Diabetic retinopathy screening

Examines neural-network analysis of retinal fundus photographs, where complex visual patterns make learned image representations especially useful. The report discusses published research and model-selection tradeoffs.

Artifact information

Title
Machine Learning vs. Deep Learning: Comparing Real-World Applications
Introduction
Different data types and project constraints call for different machine learning methods. This project compares a conventional ML workflow with a deep learning application.
Description
A written comparative report covering spam filtering, retinal image screening, features, model complexity, interpretability, and implementation tradeoffs.
Objective
Explain why traditional ML is an appropriate choice for a defined spam-filtering problem and why deep learning is an appropriate choice for complex retinal image analysis; evaluate limitations of the alternative approach in each setting.
Process
Selected two application contexts, reviewed technical examples and sources, compared data and modeling requirements, prepared a structured report, and revised the explanations to make the model-selection arguments more precise.
Tools and technologies used
Microsoft Word; published research and technical documentation; traditional ML concepts including TF-IDF and classification; deep learning concepts including convolutional neural networks.
Value proposition
Shows an ability to evaluate model choices against the data, business constraints, and risks rather than selecting a technique simply because it is more advanced.
Unique value
Connects technical reasoning with clear explanations that stakeholders without a machine learning background can follow.
Relevance
Supports my development toward data science and AI engineering roles, where choosing and communicating appropriate approaches is essential.
References
Full citations are included in the downloadable report, including Gulshan et al. (2016), Apache SpamAssassin, scikit-learn documentation, and the AIML-500 course lesson.

What this work demonstrates

  • Distinguishing conventional ML from deep learning
  • Evaluating feature engineering and learned representations
  • Explaining computational and interpretability tradeoffs
  • Supporting technical conclusions with examples and sources

Scope: This is a research and comparison report, not a claim that I trained or deployed either model.
